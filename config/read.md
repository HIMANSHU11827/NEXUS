# Configuration

NEXUS AI configuration files loaded by `config_loader.py`.

**Version:** 1.0.0

## Files
- `provider.yml` — Provider definitions (models, fallbacks, `${ENV_VAR}` key references)
- `settings.yml` — System settings (mode, memory, evolution flags)
- `nexus_config.yaml` — Runtime preferences persisted by API/TUI
- `mcp_servers.json` — MCP server definitions
