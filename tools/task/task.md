# Task Management Tool
**Version:** 2.1.0

Create, list, update, delete, and check status of checklist tasks in the active `todo.md` plan.

## Parameters
- `action` (string, required): list | create | status | get | update | delete
- `id` (string, optional): Task identifier
- `title` (string, optional): Task title
- `description` (string, optional): Task description
- `status` (string, optional): pending | in_progress | completed
