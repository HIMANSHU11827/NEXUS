# marketplace — Distribution channel for Nexus packages

## Authoritative implementation
None yet. No marketplace code, registry, or packages exist in this repository (documented as absent in `docs/MIGRATION_REPORT.md`).

## Why this directory exists
This is the approved home for a future Nexus package marketplace. The migration spec §13.6 forbids empty directories, so this README documents the intended purpose instead. **Any future marketplace package must live in `packages/<name>/`** and be registered/referenced from here.

## Notes
Keep this directory documentation-only until a real marketplace implementation exists; do not create placeholder registries or stubs.
