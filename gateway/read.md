# NEXUS Gateway

Multi-platform messaging gateway. Routes messages between NEXUS AI and external platforms.

**Version:** 1.0.0

## Platforms
- Discord, Telegram, WhatsApp, Meta, Slack, Signal, Matrix, Mattermost, Email, SMS

## Structure
The runtime path is `python -m nexus --gateway`, which imports `gateway.main`,
then uses `GatewayRunner` and the async adapters in `gateway/platforms/`.
`GatewayRunner` consumes the same dictionary stream contract as other clients:
only `{ "type": "content", "data": "..." }` records become chat replies;
status, tool, and observation records remain runtime telemetry.

Gateway adapters are lazy-loaded by `get_adapter(platform)`, so optional
dependencies for Slack, Matrix, SMS, email, or other platforms are imported only
when that platform is configured. Gateway session IDs are generated by
`gateway.session_ids.gateway_session_id()` and shared by `GatewayRunner` and
`GatewaySessionManager`, keeping memory, diagnostics, and recovery paths aligned
without storing raw chat IDs in filenames.

The older `gateway/<platform>/scripts/` files are legacy standalone adapters and
do not match the current async `BasePlatformAdapter` runtime.

## Environment
- Telegram: `TELEGRAM_BOT_TOKEN` (legacy alias: `TELEGRAM_TOKEN`)
- Discord: `DISCORD_BOT_TOKEN` (legacy alias: `DISCORD_TOKEN`)
- Slack: `SLACK_BOT_TOKEN` (legacy alias: `SLACK_TOKEN`)
- WhatsApp/Meta: `META_ACCESS_TOKEN`, optional `META_VERIFY_TOKEN`,
  optional `META_PHONE_NUMBER_ID` (legacy alias: `WHATSAPP_PHONE_ID`)
- Signal: `SIGNAL_NUMBER`
