# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| 1.0.x   | :x:                |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in NEXUS AI, please report it privately by opening a security advisory on GitHub at:

**https://github.com/himanshu/nexus-ai/security/advisories**

Do not report security vulnerabilities via public GitHub issues.

## Response Expectations

- **Acknowledgment**: within 48 hours of submission
- **Initial assessment**: within 5 business days
- **Fix timeline**: depends on severity — critical issues are prioritized and patched as soon as possible
- **Disclosure**: coordinated public disclosure after a fix is released

We appreciate responsible disclosure and will acknowledge contributors who report valid security issues.
