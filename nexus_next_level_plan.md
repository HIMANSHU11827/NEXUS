# NEXUS Next Level Plan

## Goal
Transform NEXUS from a working prototype into a production‑grade autonomous engineering agent with zero‑friction deployment, robust memory, and full‑stack observability.

## Phases

### Phase 1 – Stability & Observability
- **Canonical event stream** – Already exists, but add event replay and export to structured logs.
- **Error resilience** – Wrap every provider/tool call with automatic retry and circuit breaker.
- **Health dashboard** – Create `/api/health` with subsystem status, queue depth, memory usage.
- **Smoke tests for all 30+ providers** – Run nightly to catch regressions early.

### Phase 2 – Memory & Context
- **Long‑term memory persistence** – Move from in‑memory to SQLite/PostgreSQL vector store.
- **Conversation summarization** – Compress long sessions into hierarchical summaries.
- **User‑controlled context pruning** – Slash token costs by letting you decide what to keep.

### Phase 3 – Toolchain & Extensibility
- **Plugin marketplace** – Allow installing community tools from `.opencode/skills/` or MCP servers.
- **No‑code tool builder** – A GUI wizard to create new tools without writing Python.
- **Sandbox improvements** – Add Docker sandbox for unknown tools, then auto‑approve low‑risk commands.

### Phase 4 – Performance & Scale
- **Sub‑agent caching** – Reuse results for identical sub‑tasks across sessions.
- **Parallel tool execution** – Run independent tools concurrently via Hive.
- **Cold start under 2 seconds** – Lazy‑load all subsystems and pre‑warm the LLM provider pool.

### Phase 5 – UX & Delivery
- **One‑click install** – Single command `npx create-nexus-app` or one‑liner installer.
- **GUI improvements** – Drag‑and‑drop file panel, live code preview, real‑time event timeline.
- **Multi‑user workspaces** – Share agents and knowledge across a team.
